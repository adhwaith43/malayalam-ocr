#  Malayalam OCR – Handwritten Text Recognition
A deep learning–based OCR system that converts handwritten Malayalam text into digital form with *95%+ accuracy*. 

---


### 📌 Project Overview
The goal of this project is to automate the recognition of handwritten Malayalam script using a Convolutional Neural Network (CNN).  
The model is trained on publicly available Malayalam handwritten datasets and improved through preprocessing and augmentation.

---


### 🧠 Tech Stack
- Python
- TensorFlow / Keras
- OpenCV
- NumPy, Pandas
- Flask 

---


## Features

- ✅ Recognizes handwritten Malayalam characters  
- ✅ 95%+ recognition accuracy on validation set  
- ✅ Preprocessing pipeline:
  - Grayscale conversion  
  - Noise removal  
  - Thresholding & contour detection  
- ✅ Data augmentation for better generalization  
- ✅ Lightweight model — runs on CPU
